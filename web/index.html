                                使用已有 LoRA
                                
          
                                选择已登记的权重，或导入新文件。选择后可直接进入生成界面。
                                
          
                                
            
            
          
                                
          
                                
            
            
            
          
                                
          
                                浏览器可上传最大 45 MiB 的 .safetensors 文件。更大的权重可放到共享工作目录的 loras/（SD 1.x）、loras/sdxl/ 或 loras/anima/，再刷新列表。
                                
        
                                
        
                                
          
                                
            
                                安装与权重
                                
            
                                
            
            
                                
              
              
            
                                
            
                                训练底模可选 SD 1.x、SDXL、Iris-3B 或 Apple Silicon / MLX 上的 Anima Base 动漫模型。Anima LoRA 与 ComfyUI 兼容，模型和衍生权重仅限非商业用途；任务会记录模型修订、文件哈希、训练参数和产物。
                                
          
                                
          
                                
            
                                训练新 LoRA
                                
            
                                基于所选底模独立训练。SD 1.x 使用 512 分辨率；SDXL 使用 1024 分辨率；Anima 使用 Apple MLX 在 512 分辨率训练，可直接在本机预览。

                                选择参考图或已有训练集，也可以补充上传。勾选要用的图并编辑标注，保存时会复制成独立数据集。
