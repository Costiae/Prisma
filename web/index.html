          训练底模可选 SD 1.x、SDXL、Iris-3B 或 Apple Silicon / MLX 上的 Anima Base 动漫模型。Anima LoRA 与 ComfyUI 兼容，模型和衍生权重仅限非商业用途；任务会记录模型修订、文件哈希、训练参数和产物。
