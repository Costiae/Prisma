# Prisma 通用素材与 Prompt

这份说明供视觉小说项目复用。项目按剧本选用需要的素材，再补角色、世界观与画风。通用项描述常见演出需求，实际出场的角色、地点和音乐由各项目决定。《大圣女》的排产见[全局清单](media-checklist.md)，逐张差分见[差分规格](media-variants.md)。

## 命名与生成

素材名应说明**对象、状态和能看见或听见的区别**。例如 `小春／闭眼张口痛哭`、`小春／睁眼挂泪`、`沙萨兰海滨街景／暖墙蓝海暮色`、`身份将暴露／低弦脉冲`。同一需求的多次生成继续使用同一个素材名，候选和选定版本另记。实际演出用到的不同状态各自命名，并各自写明触发情境。

Prompt 由**项目风格、参考素材、该项变化**组成。下文的 `{{变量}}` 用已确认的项目内容填写。表里的每条「变化 Prompt」接在对应通用 Prompt 后即可作为一次独立生成请求。角色脸部和背景编辑先提供对应底图。生成后检查与底图的合成效果，再把通过的候选登记到素材名下。

## 立绘与脸部差分

**基准立绘 Prompt**

```text
为视觉小说制作角色立绘。角色为 {{角色名}}，外观为 {{年龄、五官、发型、体型}}，服装为 {{服装与饰物}}，姿势为 {{姿势与朝向}}。采用 {{项目画风}} 和 {{统一光向}}。按 {{画布规格与角色锚点}} 构图，交付干净轮廓和透明背景。表情为放松正视、自然闭口。参考 {{角色设定图}} 保持辨识特征。
```

**脸部差分 Prompt**

```text
以 {{角色名与底图名称}} 为参考，编辑 {{眉、眼、口、脸颊中实际要变的范围}}。保持角色身份、头部尺寸和角度、五官锚点、身体姿势、服装、发际线、线稿粗细和光向一致。按底图原画布和坐标交付可对齐的脸部图层。{{变化 Prompt}}
```

| 通用差分名 | 切换时机 | 变化 Prompt |
| --- | --- | --- |
| 平静正视 | 普通对白、情绪结束后回到常态 | 双眉放松，目光平稳看向对方，嘴自然闭合，脸颊保持原色。 |
| 温和闭口笑 | 道谢、安抚、平静地表达善意 | 眼尾轻弯，双侧嘴角小幅抬起，嘴唇闭合，脸颊略抬。 |
| 弯眼张口笑 | 明显开心、被逗笑 | 眼睛弯成弧形，脸颊提起，嘴张开笑，眉毛保持放松。 |
| 皱眉凝视 | 作决定、认真追问、集中注意 | 内眉轻收，眼睑稍紧，视线直视对方，唇线保持水平。 |
| 压眉张口反驳 | 当面反驳或怒斥 | 内眉明显下压，目光锁住对方，嘴张开成发话形，脸部肌肉绷紧。 |
| 睁眼微张口惊讶 | 意外信息刚出现的一拍 | 双眉上提，双眼睁大，嘴微张，保留原有头部角度。 |
| 单眉挑起疑惑 | 没听懂、发现矛盾、等待解释 | 一侧眉抬高，另一侧眉轻收，眼神仍朝对方，嘴微开。 |
| 侧目抿嘴窘迫 | 话说错、被看穿、回避对视 | 眼珠偏向画面侧下方，双唇抿紧，脸颊微红，头部沿用底图。 |
| 垂眼含泪 | 悲伤开始、努力忍住情绪 | 内眉略抬，视线下垂，下眼睑积泪，嘴闭紧，泪水留在眼眶。 |
| 闭眼张口痛哭 | 情绪爆发、哭喊 | 双眼紧闭，内眉抬起并收拢，嘴明显张开，泪水沿双颊下落。 |
| 睁眼挂泪 | 哭后恢复对视、准备再次开口 | 双眼重新睁开，唇线收回闭口，脸颊保留泪痕，眼神仍低落。 |
| 睁眼紧唇戒备 | 对方逼近、察觉威胁 | 双眼睁大，眉峰收紧，嘴唇压紧，目光朝威胁来向。 |

基础对白角色通常先选平静、笑、认真、惊讶及角色特有的一项。哭泣、脸红、戒备等按剧本加。脸部状态做成互斥图层。需要换服装、改变姿势或剪影时建立相应底图，只有通过头部对齐检查的脸层才跨底图复用。

## 场景背景

**基础背景 Prompt**

```text
制作 16:9 视觉小说背景。地点为 {{地点与用途}}，时代和建筑风格为 {{世界观}}，固定镜头为 {{机位、高度、朝向与景别}}。明确 {{关键地标与陈设}}、{{光向与时间}}，给立绘和对话框保留空间。采用 {{项目背景画风}}，画面保持统一透视。交付无角色、无界面文字的背景。
```

**背景差分 Prompt**

```text
基于 {{地点与底图名称}} 编辑同一个镜头。固定相机位置、透视、画幅、主要轮廓和画面锚点。按需要编辑光线或局部陈设，保留可复用结构。{{变化 Prompt}}
```

| 通用差分名 | 切换时机 | 变化 Prompt |
| --- | --- | --- |
| 晨光长影 | 同地清晨再次进入 | 加入清晨低角度的柔和光，保持原有建筑和道路，沿新光向延长影子。 |
| 暮色暖窗 | 傍晚时间过渡 | 天空改为暮色，朝光一侧转暖，少量窗灯初亮，保留原镜头结构。 |
| 夜景局部亮灯 | 同地夜间场景 | 压低环境亮度，用月光和指定灯源形成局部亮区，保留通道轮廓。 |
| 阴雨湿地 | 剧情出现降雨或雨后湿地 | 降低天光对比，给地面加积水和湿反光，固定地标。可动雨线作为单独效果。 |
| 浓雾遮远景 | 能见度下降或人物进入雾区 | 近景保持清晰，中远景逐层淡入雾中，固定道路和近景轮廓。 |
| 仪式陈设 | 同地点由日常变成典礼或活动场地 | 在指定位置加 {{旗帜、席位、餐桌或仪式道具}}，留出通道，保留建筑结构。 |
| 交战后损坏 | 战后重新展示同一地点 | 在指定区域加入 {{破损、翻土、折枝或碎片}}，原地标仍可辨认，烟尘可另作前景层。 |

机位或视角明显变化时另做背景。纯暗化、震屏和淡入淡出可由演出指令处理。独立出入场的陈设可以做成透明前景层。

## BGM

每首曲目以「演出用途＋听觉特征」命名。给出音乐何时进入、何时退出、是否可循环。下面每项是一种可复用的用途，项目可以按需要为同一用途写出多首可区分的曲子。

**BGM Prompt**

```text
为视觉小说创作原创配乐 {{曲名}}。使用 {{项目音乐底色}}，承接 {{剧情用途}}。编制和推进为 {{变化 Prompt}}。正文曲在对白下保持适当的密度，留出人声空间。交付 {{是否循环、循环点或结尾方式}} 的版本。需要延续主旋律时，沿用 {{项目主题动机}}。
```

| 通用用途 | 切换时机 | 变化 Prompt |
| --- | --- | --- |
| 标题主题／可记忆短动机 | 标题界面或开幕 | 用单一乐器先呈示短动机，再以弦乐或木管回应，建立项目音色。 |
| 日常对白／轻拨弦 | 稳定交谈、室内日常 | 中慢速，木管与柔和拨弦交替，旋律稀疏，起伏轻。 |
| 喜剧反应／短句留拍 | 误会、嘴硬、夸张反应 | 用短拨弦、巴松或木琴做轻巧问答，句末留空给对白反应。 |
| 探索前进／稀疏持续音 | 开始行动、进入新地点 | 用稀疏脉冲和持续音维持前进感，按地点加入少量环境色彩。 |
| 信息施压／低弦脉冲 | 审问、身份将暴露、危险渐近 | 低弦反复短音，加入间隔较长的单音，缓慢提升紧张度。 |
| 行动冲突／打击推进 | 开战或冲突升级 | 稳定节拍、清晰的打击与低弦动机，按强度渐进加入高声部。 |
| 正式仪式／弦乐与竖琴 | 典礼、会见、就任 | 慢速弦乐与竖琴，句法规整，强拍稳重。 |
| 悲伤独白／疏落钢琴 | 失去、自责、低落 | 钢琴留长间隔，低声部缓慢应答，保留尾音和沉默。 |
| 余韵收束／主题回归 | 和解、章节结束或片尾 | 把标题动机改成低密度版本，减缓节奏，形成清晰收束。 |

## CG、音效、配音与界面

| 媒介 | 命名示例 | 可复用 Prompt |
| --- | --- | --- |
| 剧情 CG | 树根救雏鸟／递药的手与微睁蓝眼 | 制作 16:9 剧情插图。按 {{场景机位}} 表现 {{事件中最关键的一瞬}}，画面焦点为 {{动作或关系}}。沿用 {{角色和地点定稿}} 的外观，明确 {{角色站位、接触点和光线}}，给对白区域留空间。 |
| 画面特效 | 治愈光／由掌心向外扩散 | 制作可叠加的 {{颜色与形状}} 特效，锚点为 {{动作位置}}。明确 {{出现、扩散、消散}} 的节拍和透明范围，保留主角五官和对白区域。 |
| 事件音效 | 石地脚步／单步硬底鞋 | 生成一个 {{物体}} 在 {{材质}} 上执行 {{动作}} 的声音，听感为 {{距离、力度、速度}}。单次事件，起音清楚，保留自然衰减，背景干净。 |
| 环境循环 | 林缘薄风／远处稀疏鸟声 | 生成 {{地点与时间}} 的环境底声，前景为 {{主要声源}}，远景为 {{次要声源}}。音量起伏轻，起止衔接自然，适合在对白下循环。 |
| 角色音色试音 | 菲亚／自然交谈试音、菲亚／急促反驳试音 | 以 {{定稿音色或已选参考}} 表演 {{试音台词}}。角色的声线、语言与发音保持一致，按 {{语气、速度、气息、重音、停顿}} 调整表演。干声交付，留出可剪辑的头尾。 |
| 对话框 | 对话框／正文与姓名板 | 为 {{项目风格}} 制作一套适用于 {{画面尺寸}} 的对话框和姓名板。保留 {{姓名与正文区域}}，让文字在浅色和深色背景上都易读。交付空白界面组件。 |
| 选择按钮 | 选项按钮／可选、聚焦、已选 | 为 {{组件与界面风格}} 制作 {{交互状态}}，按同一尺寸和内边距输出。用边框或明度区分状态，保留文字位置。 |

字体按语言覆盖和项目授权选用。立绘表情标签可以提示配音表演，实际的语气仍按台词和上下文决定。

### 可复用的声音条目

| 素材名 | 使用时机 | 变化 Prompt |
| --- | --- | --- |
| 石地硬底鞋单步 | 角色走近，脚落到石地的一拍 | 近距离单步硬底鞋，起音短而清脆，保留鞋跟触地和很短的石室回响。 |
| 木门推开与门轴轻响 | 门从闭合开始打开 | 先是轻微的门闩松动，再接低沉短促的门轴声，保留单次开门完整尾音。 |
| 衣料轻擦 | 角色起身、转身或拿起布质物件 | 近距离厚布快速轻擦一次，音量低，声音短，适合放在一句对白前。 |
| 室内静声循环 | 安静的室内对白 | 低密度室内底声，只有柔和空气感和很远的零星声响，首尾衔接自然。 |
| 街市远处人声循环 | 城镇人群在画外活动 | 多人交谈作为远处背景，词句模糊，间或传来脚步。音量平稳，首尾衔接自然。 |
| 自然交谈试音 | 确认角色日常声线 | 用日常音量和中速，按标点自然停顿，气息稳定，保持清楚咬字。 |
| 急促反驳试音 | 确认角色在冲突中的声线 | 起句短促，重读否定词，句中略加速，末尾仍清晰。沿用同一角色音色。 |
| 克制哽咽试音 | 悲伤但仍在继续说话 | 保持低音量，在句中加入短吸气，尾音轻颤，关键词保持清楚。 |
