# 《转生了的大圣女》差分规格

对应[全局多媒体素材清单](media-checklist.md)的 119 项角色差分和 14 项背景差分。每行定义一项候选素材，名称可在所属角色或地点下唯一引用。场景举例用于确定演出语义，具体挂载点等剧本校对后再定。

证据列中的「原文」表示小说有相应的动作、外观或表情描述，「演出」表示根据已出现的剧情设计了可用状态，「默认」表示该底图的常驻表情或初始状态。「可见变化」和背景表中的「改动」可以直接填入[通用素材与 Prompt](media-prompt-guide.md)的 `{{变化 Prompt}}`。实际生成时附上对应底图及角色或地点定稿。

## 参考游戏怎么用差分

从本地 Bukiyou 的 `charadefine.rpyc` 核对到，小春在 `layeredimage koharu` 下有一张常驻底图，`face` 组切换表情。下列差别通过图层预览和主剧情的切换记录交叉检查。

| 语义名称 | 参考脚本属性 | 画面变化与出现时机 |
| --- | --- | --- |
| 平静正视 | `normal` | 正视，嘴闭合。默认脸。 |
| 侧目抿嘴 | `normal2` | 眼珠偏向一侧，嘴角轻微收紧。对应 `face averting eyes.png`。 |
| 压眉抿嘴生气 | `angry` | 眉眼压低，嘴角下垂。 |
| 睁眼抿嘴落泪 | `cry` | 眼里含泪，泪珠已挂在脸上，嘴唇抿紧。第 14 个脚本段开始自责时使用。 |
| 闭眼张口痛哭 | `cry2` | 闭眼、张口、泪水增多。同段升级到尖叫时使用，脚本同时用竖向震屏。 |
| 半睁眼张口落泪 | `cry3` | 眼睛半开，眼下有泪，嘴张开。画布为 1536×1536，切换时机尚未确认。 |
| 睁眼挂泪 | `cry4` | 眼睛睁开，脸颊挂泪，嘴重新闭合。记忆恢复后使用，第 18 个脚本段也在一滴眼泪滑下时调用。 |

同一底图上的脸部组按互斥状态制作。默认脸也占一个槽位。肩颈、发际线和五官位置沿底图对齐，透明范围以成品合成效果为准。衣装底图只有在头部尺寸、角度和锚点都匹配时才能共用一套脸。像闭眼痛哭与睁眼落泪这样的差异需要分别说明，制作时才能判断是否值得独立切换。抬手、拔剑、转身等需要改身体轮廓的动作通过姿势底图、CG 或动画实现。
