# 局部重绘与表情差分

Prisma 的图像工作室支持用本地模型对 PNG 母版做遮罩重绘。它适合修正一处细节，或从已确认的 CharaDesign 母版生成表情差分。

## WebUI 操作

1. 在图像工作室候选图卡片点「局部重绘」，可直接把本地 PNG 候选载入为母版；也可以选择「本地模型」，勾选「从母版局部重绘」，再上传 PNG。
2. 当前工作画布宽高须为 64 的倍数，单边不超过 1024，总像素不超过 655,360；例如 512×896。
3. 用红色画笔涂要重绘的部分。画笔边缘是软过渡；黑色区域会保留。需要修正遮罩时可切换「擦除」或清空重画。
4. 提示词只写遮罩内的目标变化。表情差分可先用 0.35–0.4 的重绘强度，并尽量保留脸型、发型和其他身份特征。
5. 每张差分都从同一张已确认母版开始，不要把上一个差分作为下一次输入。

画布与遮罩必须同尺寸。WebUI 只接受 PNG，单个文件最大 20 MiB。选择批次张数和 LoRA 对照方式与普通本地生成相同。

## MCP 操作

调用 `image_inpaint`，传入 `prompt`、`init_image`、`mask_image`；两个图像参数是 `{ "name": "...png", "data": "data:image/png;base64,..." }`。也可以将 `data` 设为原始 base64。`mask_image` 与原图必须尺寸完全相同。可选参数包括 `strength`、`count`、`negative`、`loras`、`weight`、`seed`、`steps`、`cfg` 和 `sampler`。

任务记录会保存原图和遮罩的哈希与副本，因此可以复跑并核对输入是否一致；图像数据不会放进任务参数 JSON。

## 生成约定

- 遮罩白色/红色标记处是重绘区域，黑色处是保护区域；灰度边缘提供柔和过渡。
- 重绘强度越高，遮罩内变化越大。表情微调从较低强度开始；换发型或大件服装时使用较高强度。
- 优先在母版的工作分辨率上完成差分，再对每个差分单独做 HiRes 和 4× 放大。避免在放大后的脸部再运行自动裁切式修复。
- 未遮罩区域会按遮罩条件保留；遮罩边缘仍需逐张检查，尤其是头发、脸颊与脖颈相接处。

局部重绘是模型重新采样，不是图层级的无损修补。要生成最终表情表前，先比较几张候选并确认身份特征稳定。
